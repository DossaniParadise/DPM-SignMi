How to paste it into Outlook
Outlook on Windows (new or classic)
  1. Select "Copy signature" above.
  2. In Outlook go to Settings (gear) → Accounts → Signatures, or File → Options → Mail → Signatures.
  3. Select New, name it "DPM", click inside the editing box, and press Ctrl+V.
  4. Set it as the default for new messages and replies, then select Save.
Outlook on the web
  1. Gear icon → Account → Signatures.
  2. Paste with Ctrl+V (Cmd+V on Mac) and select Save.
iPhone / Android
  1. The Outlook mobile app only supports plain-text signatures. Paste there and the formatting is removed — that is an Outlook limit, not a problem with your copy. Set the full signature on desktop or the web and it applies when you send from there.
