How to paste it into Outlook
Outlook on Windows
  1. Click Copy signature above.
  2. In Outlook, open Settings (the gear icon), type sign in the search box, and choose Signatures.
  1. Click + Add signature (or the pencil to edit one you already have).
  1. Name it (your first name is fine), click inside the big editing box, and press Ctrl+V. Your signature appears with its formatting.
  2. Check both "Set default" boxes so it goes on new messages and replies, then click Save.

Classic Outlook (older versions): File → Options → Mail → Signatures, then paste the same way.

Outlook on the web
  1. Gear icon → Account → Signatures.
  2. Paste with Ctrl+V and select Save.
iPhone / Android
  1. The Outlook mobile app only supports plain-text signatures. Paste there and the formatting is removed — that is an Outlook limit, not a problem with your copy. Set the full signature on desktop or the web and it applies when you send from there.
